# v0.5 WAF microbenchmark

Measured: 2026-09-29

Environment:

- Windows amd64
- AMD Ryzen 7 6800H with Radeon Graphics
- Go 1.25.4
- `GOMAXPROCS=16` (reported by the Go benchmark suffix)

Command:

```text
go test ./internal/waf -run=^$ -bench=BenchmarkWAF -benchmem -count=1 -benchtime=500ms
```

Inputs include construction of an `httptest.Request` on every iteration:

- disabled: no body, benign query;
- audit/enforce no-match: benign query under an 8 KiB query limit;
- matched: a representative SQL-control query that matches `AG-1001`;
- max body: a 2 MiB no-match `text/plain` body, the maximum configurable body
  limit.

Results:

```text
BenchmarkWAF/disabled-16           401020       1582 ns/op      5188 B/op    11 allocs/op
BenchmarkWAF/audit_no_match-16     232351       2568 ns/op      6357 B/op    13 allocs/op
BenchmarkWAF/enforce_no_match-16   236827       2587 ns/op      6357 B/op    13 allocs/op
BenchmarkWAF/matched-16            186276       3244 ns/op      6534 B/op    15 allocs/op
BenchmarkWAF/max_body-16               44   12590061 ns/op  12696782 B/op    52 allocs/op
```

These are local microbenchmark observations, not throughput or latency claims
for a deployed gateway. The maximum-body case deliberately demonstrates why
the body ceiling should be set to the smallest route-appropriate value.
